# PA002. Повторы и пересказы

Один факт звучит в документе один раз. Находки:

- Факт, сформулированный дважды разными словами внутри одного раздела. Обычно это
  след генерации по кускам.
- Вводный абзац, который пересказывает заголовок раздела, и финальное резюме из уже
  сказанного.
- Факт из другого раздела, пересказанный вместо ссылки на тот раздел. Исключение
  составляет шаблон, который требует один и тот же список в обоих разделах.
- Правило из таблицы, повторённое прозой в следующем абзаце.
- Тавтология внутри фразы.

Краткое содержание в начале документа, которое требует шаблон, повтором
не считается. При правке остаётся первое упоминание факта. Повтор удаляют или
заменяют ссылкой на раздел, где факт уже сказан.

## ru

- Финальное резюме начинается с «таким образом», «итак».
- Тавтология: «совместное сотрудничество», «по-прежнему остаётся», «заранее
  предупредить».

## en

- A closing recap starts with "In summary", "Overall", "To sum up".
- A tautology: "shared common layer", "end result".
