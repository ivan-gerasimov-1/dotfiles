# PA002. Пересказы и дубли

Один факт, сформулированный дважды разными словами внутри одного раздела, обычно
остаётся от генерации по кускам. Сюда же относятся вводный абзац, который
пересказывает заголовок раздела, и финальное резюме из уже сказанного («таким
образом», «итак»).
