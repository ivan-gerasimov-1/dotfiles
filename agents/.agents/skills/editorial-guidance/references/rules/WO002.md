# WO002. Канцелярит

Сюда относятся обороты вроде «В целях экономии времени», «на данном этапе»,
«в рамках данного документа». Каждый такой оборот считается находкой WO002.
Оборот удаляй или заменяй прямым утверждением.
Канцеляризмы вроде «осуществляется», «производится», «выполняется» заменяй
конкретным глаголом. Честное «на данном этапе не требуется» одной строкой
находкой не считается.
