# WO002. Канцелярит

Канцелярские обороты удаляй или заменяй прямым утверждением. Каждый такой оборот
считается находкой WO002. Честная строка о том, что на этом этапе раздел
не нужен, находкой не считается. Существительное вместо глагола этим правилом
не ловится.

## ru

Обороты: «В целях экономии времени», «на данном этапе», «в рамках данного
документа». Честное «на данном этапе не требуется» одной строкой находкой
не считается. «Осуществляется проверка» этим правилом не ловится.

## en

- "in order to" → "to";
- "at this point in time" → "now";
- "with regard to", "in terms of" → "about", "for", or rewrite;
- "utilize" → "use";
- "in the scope of this document" → drop.
