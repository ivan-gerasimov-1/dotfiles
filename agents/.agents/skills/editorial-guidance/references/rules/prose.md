## Чек-лист (финальная проверка)

Чек-лист не повторяет правила. Он показывает, как найти нарушения. Каждую находку
разбирай по правилу, номер которого стоит в пункте.

### Проверки командой

Проверки запускает скрипт [scripts/checks.sh](../../scripts/checks.sh).
Проверки читают прозу без frontmatter и блоков кода и выдают номера строк. Пустой
вывод значит, что нарушений нет.

1. **Гибриды (P2, P3):** `scripts/checks.sh hybrids file.md`. Слово, где
   латиница склеена с кириллицей. Гибрид из [глоссария](../glossary/) или кандидат
   в глоссарий (P1) оставь, остальные замени.
2. **Латиница в прозе (P1, P2, P9):** `scripts/checks.sh latin file.md`.
   Каждое латинское слово проверь по исключениям P1. Имя кода без обратных
   кавычек оберни в обратные кавычки. Остальные англицизмы замени по P2.
3. **Варианты одного понятия (P9):** `scripts/checks.sh variants file.md`. Если у
   понятия больше одного варианта, приведи к одному. Скрипт знает только частые
   пары, остальные варианты ищи чтением. Англицизмы из P2 находят проверки 1 и 2.
4. **Соединители (P12):** `scripts/checks.sh connectors file.md`. Тире и точка с
   запятой в прозе и в прозаических ячейках таблиц. Скрипт пропускает исключения
   P12, которые может узнать сам:
   - заголовки;
   - пункты «A vs B»;
   - заголовок в подбор с тире после него;
   - точку с запятой в конце пункта списка;
   - ячейки короче шести слов.

   Определение термина оставь, остальное перепиши отдельными предложениями. Двоеточия ищи глазами по всей прозе.
5. **Многоточие (P4):** `scripts/checks.sh ellipsis file.md`. В прозе замени на
   «и так далее», в таблицах оставь.
6. **Длинные предложения (P5):** `scripts/checks.sh long-sentences file.md`.
   Выдаёт предложения длиннее 25 слов с номерами строк. Это кандидаты. Разбей те, где больше двух
   придаточных.
7. **Ссылки на строки кода (P11):** `scripts/checks.sh file-lines file.md`.
   Только для долгоживущих документов. Исключения перечислены в P11.
8. **Битые ссылки (P11):** `scripts/checks.sh links file.md`. Ссылка ведёт на файл
   или каталог, которого нет. Якоря скрипт не проверяет.

### Проверки чтением

9. **Род (P4).** Окончания согласованы с родом имён кода.
10. **Вода и повторы (P6, P7).** Для каждого абзаца: можно ли убрать предложение
   без потери смысла? Повторён ли факт из другого раздела вместо ссылки (P11)?
11. **Заголовки и пункты списков (P2, P15).** В заголовках нет англицизмов и гибридов.
    В пункте списка нет перечня из трёх и более групп.
