# WO004. Без метафор

Метафору, которую автор придумал для этого текста, заменяют прямым словом.
Метафора, ставшая термином, находкой не считается. Ею называют понятие
в документации и в разговоре, и прямого слова, которое читатель понял бы
быстрее, у неё нет. Собственное имя артефакта не трогают, даже если оно образное.

## ru

- «крыша», «зонтик», «крышевой документ» → «обзор», «верхнеуровневый документ»
  или «точка входа в набор документов».
- Не находка: «узкое место», «утечка памяти», «горячий путь», «ветка», «шлюз».
- Образное имя артефакта, например «Карта …», остаётся.

## en

- "umbrella document", "north star", "deep dive", "single pane of glass" → say
  it directly: "overview", "goal", "detailed review", "one view".
- Not a finding: "bottleneck", "memory leak", "hot path", "branch", "gateway".
