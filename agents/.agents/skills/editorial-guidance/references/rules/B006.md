# B006. Однородность ритма

Прочитай подряд три случайных раздела. Если длина предложений, структура абзацев
и место жирного текста совпадают до взаимозаменяемости, отметь это. Живой
автор пишет неровно, поэтому идеально ровный ритм по всему длинному документу
указывает на модель.
