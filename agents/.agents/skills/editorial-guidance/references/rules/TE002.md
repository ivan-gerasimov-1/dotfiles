# TE002. Англицизмы без технической нагрузки — заменять

Слово надо заменять, если у него есть нормальный русский эквивалент, оно НЕ имя класса/модуля/технологии и не входит в раздел «Не переводить» глоссария. Правило действует и в заголовках, например «Single write point» → «Единая точка записи», «Runtime-ветвления» → «Ветвления во время выполнения». Типовые замены лежат в разделе «Заменять» [глоссария](../glossary/), в общем и в проектном.
