# P003. Гибриды русского и английского недопустимы

Гибрид заменяется чистым русским словом или чистым английским термином в формате кода. Для части гибридов готовая замена есть в таблице P002. Примеры: `сабмитнуть`, `дискардить`, `дроп-нуть`, `комит-нуть`, `sync-пайплайн`, `runtime-свитч`, `submit-форма`, `cart-сессия`, `checkout-конфиг`, `payment-сессия`, `UI-механики`.

Окончания и приставки нельзя клеить к английским корням, если есть русское слово. Прилагательное-приставка «english-кириллица» через дефис почти всегда плохо. Исключение составляют гибриды из исключений P001 (`lazy-чанк`, `feature-флаг`).
