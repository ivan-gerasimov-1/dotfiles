# CA005. Рубленый ритм

Рубленый ритм — три и больше предложений подряд, каждое не длиннее 12 слов,
когда хотя бы между двумя соседними есть причина, следствие, противопоставление
или уступка, но связки нет. Читатель сам достраивает, как факты связаны. Находка
одна на абзац или пункт списка.

Связь называют союзом или подчинением: «поэтому», «потому что», «но», «при этом»,
«зато», «если». Связку ставят только там, где связь уже есть в тексте. Новую
причину или следствие правка не выдумывает. Слитое предложение не должно
получить три и больше придаточных.

Находкой не считаются:

- независимые факты, между которыми связи нет;
- параллельные факты одного строения («A делает X. B делает Y.»). Их можно
  сопоставить, но противопоставления между ними нет;
- шаги инструкции и пункты списка, каждый со своим фактом;
- таблицы, метки и блоки кода.

## ru

Было: «Сервис читает конфиг при старте. Изменения без перезапуска не видны.
Перезапуск занимает около минуты. На это время запросы уходят на резервный
узел.»
Стало: «Сервис читает конфиг только при старте, поэтому изменения без перезапуска
не видны. Перезапуск занимает около минуты, и на это время запросы уходят
на резервный узел.»

Остаётся: «Сервис написан на Go. Логи пишутся в stdout. Метрики отдаются
на порту 9090.» Это независимые факты.

Остаётся: «Продюсер объявляет формат сообщения. Консьюмер объявляет, какие поля
читает. Каждая сторона описывает только себя.» Первые два факта параллельны,
и «а» между ними связи не добавит.

## en

Before: "The service reads its config at startup. Changes need a restart.
A restart takes about a minute. Requests go to the standby node meanwhile."
After: "The service reads its config only at startup, so changes need a restart.
A restart takes about a minute, and requests go to the standby node meanwhile."

Stays: "The service is written in Go. Logs go to stdout. Metrics are served
on port 9090." These facts are independent.

Stays: "The producer declares the message format. The consumer declares the
fields it reads. Each side describes only itself." The first two facts are
parallel, and "while" between them adds no relation.
