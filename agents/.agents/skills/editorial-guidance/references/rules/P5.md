# P5. Структура и стиль предложений

- **Фраза с тремя и более придаточными → 2–3 предложения.** Особенно во вводном абзаце документа и в списках принятых решений.
- **Не начинать пункт списка с подлежащего, которое уже есть в заголовке.** Если раздел называется «Поле `isPaid`», пункт «Поле `isPaid` пишет бэкенд» повторяет заголовок. Пишут «Пишет бэкенд при оплате `Order`».
- **Списки и таблицы предпочтительнее свободного текста**, если описывается набор однородных пунктов (изменения, поля схемы, граничные случаи, точки расширения). Список оправдан, когда пункты различаются по содержанию. Пункты одной формы, где меняется одно слово, считаются находкой A3.
- **Пассив допустим там, где он естественнее активного** («поле добавляется», «миграции не нужны»), но не злоупотреблять.
- **Избегать тяжёлых деепричастных оборотов в начале предложения.**
- **Канцеляризмы** вроде «осуществляется», «производится», «выполняется» заменять конкретным глаголом по P13. Обороты вроде «в целях…», «на данном этапе», «в рамках данного документа» удалять или заменять прямым утверждением. Честная строка из исключения A3 остаётся.
