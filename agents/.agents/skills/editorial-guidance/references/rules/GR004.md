# GR004. Полные предложения вместо конспекта

Проза пишется полными предложениями. Правило проверяет прозу, пункты списков
и прозаические ячейки таблиц. Каждое вхождение считается находкой:

- часть предложения без сказуемого там, где оно нужно;
- два самостоятельных утверждения через запятую без союза;
- утверждение в скобках на месте придаточного;
- пропущенное подлежащее, которого нет ни в заголовке, ни в предыдущей фразе.

Находкой не считаются заголовки, метки и метаданные в строке («Статус:
черновик»), перечни значений, пункты с заголовком в подбор, таблицы данных,
ячейки таблиц с именной фразой («Счётчик повторных попыток по задаче»).
Пояснение или пример в скобках тоже остаётся.
Не считается находкой и подлежащее, опущенное потому, что оно есть в заголовке.

При правке возвращают сказуемое, союз или подлежащее либо разбивают утверждения
на два предложения. Союз выбирают по связи, которая есть в тексте. Если связи
нет, точка лучше союза. Новых фактов правка не добавляет. Если сказуемое без догадки не восстановить, задай вопрос автору.

## ru

- Нет сказуемого. Было: «Команда переводит сервисы на новую очередь, среди них
  сервис уведомлений». Стало: «Команда переводит сервисы на новую очередь,
  в том числе сервис уведомлений».
- Утверждения через запятую. Было: «Кэш хранит ответ 10 минут, при записи
  сбрасывается». Стало: «Кэш хранит ответ 10 минут и сбрасывается при каждой
  записи».
- Скобка вместо придаточного. Было: «Импорт принимает только CSV (Excel позже)».
  Стало: «Импорт пока принимает только CSV. Excel он начнёт принимать позже».
- Остаётся: ячейка «Счётчик повторных попыток по задаче», метка «Срок: Q4».

## en

- No verb: "Several services on the new queue, notifications among them" →
  "Several services run on the new queue, notifications among them".
- A comma splice: "The cache keeps a response for 10 minutes, a write clears
  it" → "The cache keeps a response for 10 minutes, and a write clears it".
- A clause hidden in parentheses: "Import accepts CSV only (Excel later)" →
  "For now import accepts only CSV. Excel support comes later".
- Stays: a cell "Retry counter per job", a label "Owner: platform team".
