# WO001. Кальки

Находкой считается оборот, дословно переведённый с другого языка: в русском
тексте с английского, в английском с русского. Если обратный перевод даёт
готовую идиому другого языка, это калька.

Правило ловит связный оборот. Отдельное английское слово, гибрид, полуперевод
одного слова и метафора этим правилом не ловятся.

## ru

Примеры: «безопасна по построению» (safe by construction), «несущие правила»
(load-bearing). Устоявшиеся кальки из разделов «Допустимые кальки»
в [глоссарии](../glossary/) не помечай, новые помечай.

## en

- False friends: "actual" (актуальный) → "current", "up to date";
  "realize" (реализовать) → "implement"; "functional" as a noun (функционал)
  → "functionality", "features"; "control" (контроль) → "check", "monitoring";
  "exploitation" (эксплуатация) → "operation"; "perspective" (перспектива)
  → "prospects".
- Calqued phrases: "the idea is following" → "here's the idea", or state it;
  "discuss about" → "discuss"; "make a meeting" → "hold a meeting";
  "annulate" → "void", "cancel"; "overthere" → "there".
- Calqued grammar: "worth to do" → "worth doing". Other grammar mistakes are
  not calques.
