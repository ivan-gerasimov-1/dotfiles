# ST008. Ссылки вне блоков кода

Ссылка внутри блока кода не кликается. Находкой считается URL или ссылка
в формате Markdown внутри блока кода. Исключение составляет URL, который в коде
служит значением: в конфиге, в запросе, в примере вызова.

При правке ссылку выносят из блока в список ссылок в конце документа или в прозу,
где она нужна по смыслу. Ссылку оформляют в формате Markdown с понятным текстом.
Ссылки на другие задачи и пул-реквесты остаются в прозе.

## ru

Было: строка `TD: https://wiki.example.com/td-123` внутри блока кода.
Стало: пункт «Тех. дизайн: [расписание платежей](https://wiki.example.com/td-123)»
в разделе «Ссылки».

## en

Before: the line `TD: https://wiki.example.com/td-123` inside a code block.
After: the item "Tech design: [payment schedule](https://wiki.example.com/td-123)"
in the "Links" section.
