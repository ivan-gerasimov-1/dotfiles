# ST003. Навигация и ссылки

- **Якорные ссылки внутри документа.** При упоминании другого раздела этого
  документа ставь ссылку на его якорь `(#anchor)`. Якорь должен совпадать
  с заголовком раздела. У текста из чата якорей нет.
- **Файлы и строки кода не фиксировать в долгоживущих документах.** Дизайн-документ
  или RFC должен жить минимум полгода, а номера строк устаревают с первым
  рефакторингом. Номер строки убирают, имя файла, сервиса или функции остаётся.
  Имя, которого в тексте нет, не выдумывают. В картах кода, исследованиях
  и отчётах ссылки `file:line` служат доказательством утверждения, их не трогают.
  Если по тексту неясно, долгоживущий ли документ, спроси автора.
- **Битые ссылки.** Ссылку на несуществующий файл не удаляют. Если файл с тем же
  именем нашёлся рядом, ссылку исправляют, иначе задают вопрос автору.
