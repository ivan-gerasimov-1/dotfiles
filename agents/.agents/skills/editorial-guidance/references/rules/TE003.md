# TE003. Гибриды русского и английского недопустимы

Гибрид заменяется русским словом или английским термином без русских окончаний
и приставок. В формат кода английский термин берут, только если это имя кода.
Для части гибридов готовая замена есть в разделе «Заменять» [глоссария](../glossary/).
Примеры: `сабмитнуть`, `дискардить`, `дроп-нуть`, `комит-нуть`, `sync-пайплайн`,
`runtime-свитч`, `submit-форма`, `cart-сессия`, `checkout-конфиг`, `payment-сессия`.

Окончания и приставки нельзя клеить к английским корням, если есть русское слово.
Английское слово через дефис перед русским почти всегда плохо. Исключение
составляют гибриды из раздела «Не переводить» глоссария (`lazy-чанк`, `feature-флаг`).
Аббревиатура через дефис перед русским словом («API-ключ», «CI-пайплайн»,
«e2e-тесты») гибридом не считается.
