# P15. Перечень внутри пункта списка ≥ 3 элементов — разбить

Если пункт списка перечисляет три и более группы, превращать его во вложенный список. Шаблон:

- **Заголовок зоны.**
  - Первая группа.
  - Вторая группа.
  - Третья группа.

Не вмещать «пункт меню; страница списка; редактор с 13 + 6 вкладок; значение в фильтре» в одну строку.

Заголовок в подбор ставь, только если без него группа непонятна. Одинаковые заголовки в подбор во всех пунктах подряд дают однородный ритм (B6). Вместе с фразой-заходом перед ними они образуют паттерн B3.
