# A5. Правдоподобная выдумка

Сюда относятся детали, которые звучат конкретно, но ни из чего не следуют.
Например, это числа без источника и без роли в решении или ссылки, которые никуда
не ведут. Сюда же относятся названия систем и документов, на которые опирается
вывод, хотя в тексте нет ни ссылки, ни объяснения. Название, упомянутое один раз, само по себе
находкой не считается. Такие детали помечай как подозрение. Проверить такую деталь может
только автор.
