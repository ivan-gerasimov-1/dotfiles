# SU002. Симметричные пустые структуры

LLM тяготеет к спискам одинаковой формы, где форма первична, а содержание
подгоняется. Находки:

- пункты-близнецы, где меняется одно слово, а утверждение то же;
- таблицы, где колонка заполнена вариациями «да/поддерживается/используется»;
- разделы, существующие ради полноты шаблона, из одного абзаца общих слов без фактов.
  Честное «на данном этапе не требуется» одной строкой слопом не считается.
