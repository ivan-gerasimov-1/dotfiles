# prose

Правила языка: термины, грамматика и читаемость. Термины берутся из
[глоссария](../glossary/).

## Проходы

Каждый проход ищет нарушения по пунктам чек-листа ниже для своих правил. Проход
«Грамматика и построение предложений» проверяет ещё обычные ошибки русского языка
(согласование, падежи, запятые) и пункт 6 чек-листа.

## Чек-лист (финальная проверка)

Чек-лист не повторяет правила. Он показывает, как найти нарушения. Каждую находку
разбирай по правилу, номер которого стоит в пункте.

### Проверки командой

Проверки запускает скрипт `scripts/checks.sh`.
Проверки читают прозу без frontmatter и блоков кода и выдают номера строк. Пустой
вывод значит, что нарушений нет.

1. **Гибриды (TE002, TE003):** `scripts/checks.sh hybrids file.md`. Слово, где
   латиница склеена с кириллицей. Гибрид из [глоссария](../glossary/) или кандидат
   в глоссарий (TE001) оставь, остальные замени.
2. **Латиница в прозе (TE001, TE002, TE004):** `scripts/checks.sh latin file.md`.
   Каждое латинское слово проверь по исключениям TE001. Имя кода без обратных
   кавычек оберни в обратные кавычки. Остальные англицизмы замени по TE002.
3. **Варианты одного понятия (TE004):** `scripts/checks.sh variants file.md`. Если у
   понятия больше одного варианта, приведи к одному. Скрипт знает только частые
   пары, остальные варианты ищи чтением. Англицизмы из TE002 находят проверки 1 и 2.
4. **Соединители (GR003):** `scripts/checks.sh connectors file.md`. Тире и точка с
   запятой в прозе и в прозаических ячейках таблиц. Скрипт пропускает исключения
   GR003, которые может узнать сам:
   - заголовки;
   - пункты «A vs B»;
   - заголовок в подбор с тире после него;
   - точку с запятой в конце пункта списка;
   - ячейки короче шести слов.

   Определение термина оставь, остальное перепиши отдельными предложениями. Двоеточия ищи глазами по всей прозе.
5. **Многоточие (GR001):** `scripts/checks.sh ellipsis file.md`. В прозе замени на
   «и так далее», в таблицах оставь.
6. **Длинные предложения (ST001):** `scripts/checks.sh long-sentences file.md`.
   Выдаёт предложения длиннее 25 слов с номерами строк. Это кандидаты. Разбей те, где больше двух
   придаточных.
7. **Ссылки на строки кода (ST003):** `scripts/checks.sh file-lines file.md`.
   Только для долгоживущих документов. Исключения перечислены в ST003.
8. **Битые ссылки (ST003):** `scripts/checks.sh links file.md`. Ссылка ведёт на файл
   или каталог, которого нет. Якоря скрипт не проверяет.

### Проверки чтением

9. **Род (GR001).** Окончания согласованы с родом имён кода.
10. **Вода и повторы (PA003, PA004).** Для каждого абзаца: можно ли убрать предложение
   без потери смысла? Повторён ли факт из другого раздела вместо ссылки (ST003)?
11. **Заголовки и пункты списков (TE002, ST004).** В заголовках нет англицизмов и гибридов.
    В пункте списка нет перечня из трёх и более групп.

## Правка

После правок пройди чек-лист выше по всему тексту.
