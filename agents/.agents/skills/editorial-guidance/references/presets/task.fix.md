# Правка пресета task

Первой правится группа «Устройство задачи». Остальные группы проверяют уже
перестроенный текст. Во флоу parallel сабагенты остальных групп запускаются после
того, как правки первой группы применены.

После всех правок перечитай описание целиком. Правки других групп не должны
вернуть имена кода в прозу, чекбоксы в критерии и ссылки в блоки кода.
