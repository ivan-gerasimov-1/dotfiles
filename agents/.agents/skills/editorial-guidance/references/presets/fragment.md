# fragment

Правила, которые можно проверить на нескольких предложениях из выделения или
из чата. Оценки слопа нет. На коротком тексте правила читаются так:

| Правило | Что проверяется |
|---|---|
| A001 | маркер виден в одной фразе |
| A002 | только если в тексте есть вывод или «зачем/почему» |
| B001 | каждое вхождение, без подсчёта плотности |
| B004 | калька видна в одной фразе |
| P001–P003 и глоссарий | термины и гибриды |
| P010, P015 | только для ячейки таблицы или пункта списка |
