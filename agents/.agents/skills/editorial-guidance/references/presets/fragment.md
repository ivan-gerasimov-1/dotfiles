# fragment

Правила, которые можно проверить на нескольких предложениях из выделения или
из чата. Оценки слопа нет. На коротком тексте правила читаются так:

| Правило | Что проверяется |
|---|---|
| PA001 | маркер виден в одной фразе |
| SU001 | только если в тексте есть вывод или «зачем/почему» |
| CA001 | каждое вхождение, без подсчёта плотности |
| WO001 | калька видна в одной фразе |
| TE001, TE002, TE003 и глоссарий | термины и гибриды |
| ST002, ST004 | только для ячейки таблицы или пункта списка |
