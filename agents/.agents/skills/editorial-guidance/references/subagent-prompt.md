# Задание сабагенту

Задание для сабагента прохода во флоу [parallel](flows/parallel.md). Значения
для одного прохода основной берёт из строки вывода `rules.sh --passes`.

```
Ты выполняешь проход <номер> «<название>» пресета <пресет> редакторской
вычитки по скиллу editorial-guidance.

Входные данные:
- каталог скилла: <путь>;
- документ: <путь к файлу>;
- язык текста: <ru|en>;
- выбранные правила: <все номера из вывода `rules.sh --passes`>;
- правила прохода: <номера правил>;
- проектный глоссарий: <путь к каталогу или «нет»>.

В одном ходе, отдельными вызовами, прочитай в каталоге скилла:
- references/overlaps.md;
- вывод `<каталог скилла>/scripts/rules.sh <ru|en> --notes <пресет>`;
- вывод `<каталог скилла>/scripts/rules.sh <ru|en> <номера правил> GR003 CA001`.

Если правила прохода ссылаются на глоссарий, для русского текста прочитай все
файлы references/glossary/ и проектного глоссария. Для английского текста общий
глоссарий не нужен, проектный читай только ради имён продукта и кода.

Как работать:
- Цитируемые промпты и их схемы, блоки кода, Mermaid и таблицы данных
  не проверяй. Таблица данных содержит числа, конфиги или перечни значений
  без оценочных слов, колонки-заглушки ею не считаются. Заголовки
  и прозаические ячейки таблиц проверяй.
- Проверяй документ только по правилам прохода. Пункты чек-листа пресета для
  этих правил тоже твои. GR003 и CA001 выведены, чтобы проверять по ним замены,
  находки по ним ищи, только если они входят в проход.
- Пересечения разводи по overlaps.md с учётом всех выбранных правил,
  включая правила других проходов.
- Механические проверки запускай через scripts/checks.sh из каталога скилла.
- Документ не правь.
- Каждую замену проверь по GR003 и CA001. Замена не должна вносить новый
  соединитель или контраст.
- Не меняй порядок мыслей. Неясное место не толкуй, верни его вопросом к автору.

Что вернуть:
1. Список находок. Для каждой укажи:
   - правило;
   - точную цитату из документа, достаточную для однозначного поиска;
   - замену или «удалить»;
   - причину в одну строку.
2. Отдельный список вопросов к автору: подозрения SU003 и правки, которым нужен
   факт, которого в документе нет.
```
