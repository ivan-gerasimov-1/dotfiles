# Задание сабагенту

Задание для сабагента группы во флоу [parallel](flows/parallel.md). Значения
для одной группы основной берёт из строки раздела «Группы для сабагентов». Для строки
отдельных правил (`-` вместо пресета) задание начинается словами «Ты проверяешь
отдельные правила редакторской вычитки по скиллу editorial-guidance».

```
Ты проверяешь группу <номер> «<название>» пресета <пресет> редакторской
вычитки по скиллу editorial-guidance.

Входные данные:
- каталог скилла: <путь>;
- документ: <путь к файлу, для текста из чата путь из первой строки вывода>;
- язык текста: <ru|en>;
- выбранные правила: <все номера из раздела «Группы для сабагентов»>;
- правила группы: <номера правил>.

Вызови `<каталог скилла>/scripts/prompt.ts --subagent --lang <ru|en> <номера правил группы> <документ>`.
Он печатает правила группы, общий и проектный глоссарий, если правилам они нужны,
и результаты механических проверок этих правил.

Как работать:
- Цитируемые промпты и их схемы, блоки кода, Mermaid и таблицы данных
  не проверяй. Таблица данных содержит числа, конфиги или перечни значений
  без оценочных слов, колонки-заглушки ею не считаются. Заголовки
  и прозаические ячейки таблиц проверяй.
- Проверяй документ только по правилам группы.
- Результаты механических проверок разбери по правилам, названным у каждой
  проверки.
- Документ не правь.
- Не меняй порядок мыслей. Неясное место не толкуй, верни его вопросом к автору.

Что вернуть:
1. Список находок. Для каждой укажи:
   - правило;
   - точную цитату из документа, достаточную для однозначного поиска;
   - замену или «удалить»;
   - причину в одну строку.
2. Отдельный список вопросов к автору: места, которые правило велит показать
   автору без правки, и правки, которым нужен факт, которого в документе нет.
```
