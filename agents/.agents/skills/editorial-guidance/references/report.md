# Шаблон отчёта

Отчёт выдаётся без `--fix`, текст при этом не правится. Порядок разделов
фиксирован. Раздел без содержания пропускай.

## Шаблон

```markdown
Слоп: N/5. <одно предложение почему>

**Антислоп-сигналы**
- `file.md:8` «цитата». Почему это живое место.

**Находки**
- **A002** `file.md:14` «цитата» → «замена». Причина.
- **B001** `file.md:20` «цитата» → «замена». Причина. Счёт: 3 на 1000 слов, порог: 1.
- **P012** `file.md:31` «цитата» → «замена». Причина.

**Оставлено**
- **B001** `file.md:40` «цитата». Почему правка потеряет смысл.

**Вопросы к автору**
- **A005** `file.md:52` «цитата». Что нужно уточнить.

**Кандидаты в глоссарий**
- «термин». Где встречается и почему его стоит закрепить.

**Рекомендация**
Один самый выгодный следующий шаг.
```

## Как заполнять

- **Оценка слопа** идёт первой строкой, только если выбран свод slop
  и проверяется документ. Шкала и правила подсчёта описаны
  в [rules/slop.md](rules/slop.md#оценка). У фрагмента оценки нет.
- **Антислоп-сигналы** нужны, только если выбран свод slop. Это живые места
  документа, например цены решений, числа, признанные компромиссы.
- **Находки** идут в порядке номеров правил, сначала A, потом B, потом P.
  Одна находка занимает одну строку. Вместо замены может стоять «удалить».
  Для B001–B003 добавь счёт вхождений и порог из правила.
- **Оставлено** перечисляет вхождения, которые правило ловит, но правка
  потеряет смысл.
- **Вопросы к автору** содержат подозрения A005 и правки, которым нужен факт,
  которого в тексте нет.
- **Кандидаты в глоссарий** собираются по P001.
- **Рекомендация** нужна, только если выбран свод slop.
- У фрагмента из чата нет места в файле, поэтому `file.md:line` в строках опускается.
