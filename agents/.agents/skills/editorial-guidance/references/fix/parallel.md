## Порядок правки

Пресеты идут по одному, в порядке строк «Группы для сабагентов». Отдельные правила
идут первыми, как свой пресет. Следующий пресет проверяет уже исправленный текст.

1. Основной запускает сабагентов для групп пресета параллельно.
2. Он применяет их правки по разделу «Режим правки», дубли отбрасывает. Если две
   правки задевают одно предложение, первой применяется правка группы с меньшим
   номером. Вторую основной проверяет на уже изменённом тексте.
