# Режим правки

Текст правится, а не только проверяется. Порядок правки для флоу задан ниже.

- Правки вносятся через Edit, по одному точечному изменению. Место правки
  находится по цитате, потому что номера строк после первых правок сдвигаются.
- Текст из чата верни исправленным.
- Правится каждая находка. Что считается находкой, задают правила и тексты
  выбранных пресетов.
- Если для правки нужен факт, которого в документе нет, не выдумывай его. Задай
  вопрос автору.
- Технические факты, числа и имена кода не меняются. Смысл каждого утверждения
  сохраняется. Если сомневаешься в смысле, спроси автора.
- Вхождение, у которого любая переформулировка теряет смысл (например, контраст
  «X, а не Y», где противопоставление и есть утверждение), оставь.
- Правка не должна порождать находку по другому выбранному правилу. Например,
  раздробленное предложение не должно дать ровный машинный ритм.
- Разделы «Правка пресета» дополняют эти правила для своего пресета.
