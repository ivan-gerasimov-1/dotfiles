# Режим правки

Текст правится, а не только проверяется. Порядок правки для флоу задан ниже.

- Правки вносятся через Edit, по одному точечному изменению. Каждое вхождение
  требует своего решения, а дифф должен читаться по одной правке. Место правки
  находится по цитате, потому что номера строк после первых правок сдвигаются.
- Скрипты, sed и регулярные выражения текст не меняют, даже когда находки
  однотипные. Замена по шаблону не отличает случаи, которые правило разводит.
- Текст из чата верни исправленным.
- Правится каждая находка.
- Если для правки нужен факт, которого в документе нет, не выдумывай его. Задай
  вопрос автору.
- Технические факты, числа и имена кода не меняются. Смысл каждого утверждения
  сохраняется. Если сомневаешься в смысле, спроси автора.
- Вхождение, у которого любая переформулировка теряет смысл, оставь. Так бывает,
  когда сама форма оборота и есть утверждение.
- Правка не должна порождать находку по другому выбранному правилу. Например,
  исправленное предложение не должно сделать абзац однообразнее, чем он был.
- Разделы «Правка пресета» дополняют эти правила для своего пресета.
