# Как проверять

Действует для любого агента, который проверяет текст, основного и сабагента.

## Что не проверяется

Цитируемые промпты и их схемы, блоки кода, Mermaid и таблицы данных не правятся
и в находки не попадают. Таблица данных содержит числа, конфиги или перечни
значений без оценочных слов. Колонки-заглушки из SU002 таблицей данных не считаются.
Заголовки и прозаические ячейки таблиц проверяются.

## Где правила пересекаются

У каждой находки один владелец. Так одно место не правится дважды по разным правилам.

- **Наполнители.** Фраза из закрытого списка PA001 или её форма записывается по PA001.
  Похожая фраза не из списка, прочая вода и мета-фразы идут по PA003.
- **Усиление.** Если всё следствие нельзя опровергнуть («значительно повышает
  надёжность»), находка идёт по SU001. Если утверждение проверяемое и лишнее только
  усиление, находка идёт по PA001.
- **Повторы.** Один факт, пересказанный другими словами внутри одного раздела,
  а также вводный абзац, пересказывающий заголовок, и резюме из уже сказанного
  записываются по PA002. Повтор факта из другого раздела, повтор таблицы прозой
  и тавтология внутри фразы идут по PA004.
- **Лишнее предложение.** Вывод или пункт «зачем/почему» без проверяемого
  утверждения записывается по SU001. Прочие предложения, которые можно убрать без
  потери смысла, идут по PA003.
- **Канцелярит.** Канцелярский глагол при отглагольном существительном
  («осуществляется проверка») записывается по WO002.
- **Пустые структуры.** Список или таблица из пунктов одной формы, где меняется
  одно слово, записывается по SU002.
- **Знаки препинания.** Двоеточие в короткой метке или в метаданных записывается
  по GR001. Тире, двоеточие и точка с запятой как соединители внутри предложения
  идут по GR003.
- **Варианты терминов.** Разнобой из-за англицизма или гибрида («рефанд» рядом
  с «возвратом») записывается по TE002 или TE003. Разнобой русских вариантов одного
  понятия идёт по TE004.
- **Кальки и англицизмы.** Связный русский оборот, дословно переведённый
  с английского, записывается по WO001. Полуперевод, который не читается по-русски
  («сайты» в значении call sites), идёт по GR002. Английское слово или гибрид
  в русском тексте идут по TE002 или TE003.
- **Метафоры.** Метафора, которая заодно калька («зонтичный документ» от umbrella
  document), записывается по WO004.

Если владелец не выбран, находку получает выбранное правило из той же пары.
Находка, которая не ложится ни на одно выбранное правило, не ищется.
