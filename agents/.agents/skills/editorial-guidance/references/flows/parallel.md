# parallel

Каждую группу проверяет отдельный сабагент. Сабагенты только ищут и предлагают
правки. Отчёт собирает и файл правит один агент, тот, что запустил скилл. Дальше
он называется основным.

Группы выведены `rules.sh <ru|en> --groups <селекторы>`. Одна строка задаёт одну
группу: пресет, номер группы в пресете, название и выбранные правила группы.
Первой может идти строка с `-` вместо пресета и номера. Она собирает отдельные
правила, их проверяет один сабагент.
Тексты пресетов выведены `rules.sh <ru|en> --notes <селекторы>`.

Задание сабагенту приведено ниже. Основной подставляет значения в угловых скобках
и отправляет задание каждому сабагенту.

## Без `--fix`

1. Основной запускает сабагентов для всех групп параллельно.
2. Он убирает дубли и собирает отчёт по шаблону.

## С `--fix`

Пресеты идут по одному, в порядке строк `--groups`. Отдельные правила идут
первыми, как свой пресет. Следующий пресет проверяет уже исправленный текст.

1. Основной запускает сабагентов для групп пресета параллельно.
2. Он применяет их правки по разделу «Правка», дубли отбрасывает. Если две правки задевают одно предложение, первой
   применяется правка группы с меньшим номером. Вторую основной проверяет на уже
   изменённом тексте.
3. После последнего пресета основной выполняет раздел «Правка» из текста каждого
   выбранного пресета.

Сабагент не может запустить своих сабагентов. Если скилл сам работает внутри
сабагента, проверка идёт во флоу single.
