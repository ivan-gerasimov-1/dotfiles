# parallel

Каждый проход выполняет отдельный сабагент. Сабагенты только ищут и предлагают
правки. Отчёт собирает и файл правит один агент, тот, что запустил скилл. Дальше
он называется основным.

Проходы выведены `rules.sh <ru|en> --passes <селекторы>`. Одна строка задаёт один
проход: пресет, номер прохода в пресете, название и выбранные правила прохода.
Тексты пресетов выведены `rules.sh <ru|en> --notes <селекторы>`.

Задание сабагенту приведено ниже. Основной подставляет значения в угловых скобках
и отправляет задание каждому сабагенту.

## Без `--fix`

1. Основной запускает сабагентов для всех проходов параллельно.
2. Он разводит пересечения по разделу «Где правила пересекаются», убирает дубли
   и собирает отчёт по шаблону. Если у выбранного пресета есть чек-лист перед
   оценкой, перед оценкой он сверяется с ним.

## С `--fix`

Пресеты идут по одному, в порядке строк `--passes`. Следующий пресет проверяет
уже исправленный текст.

1. Основной запускает сабагентов для проходов пресета параллельно.
2. Он применяет их правки по разделу «Правка». Пересечения разводит по разделу
   «Где правила пересекаются». Если две правки задевают одно предложение, первой
   применяется правка прохода с меньшим номером. Вторую основной проверяет на уже
   изменённом тексте.
3. После последнего пресета основной выполняет раздел «Правка» из текста каждого
   выбранного пресета.

Сабагент не может запустить своих сабагентов. Если скилл сам работает внутри
сабагента, проверка идёт во флоу single.
