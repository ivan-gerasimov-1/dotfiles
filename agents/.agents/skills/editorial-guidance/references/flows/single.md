# single

Всю проверку ведёт один агент, без сабагентов. Дальше он называется основным.
Правила и тексты пресетов уже выведены `rules.sh <ru|en> <селекторы>`.

1. Если проверяется файл, запусти `scripts/checks.sh` для выбранных правил.
   Какие проверки к каким правилам относятся, написано в чек-листах пресетов,
   а без аргументов скрипт выводит их список. У текста из чата механических
   проверок нет.
2. Проверь текст по выбранным правилам, по проходам пресетов по порядку.
   Пересечения разведи по разделу «Где правила пересекаются».
3. Без `--fix` ничего не правь и верни отчёт по шаблону. Если у выбранного
   пресета есть чек-лист перед оценкой, перед оценкой сверься с ним.
4. С `--fix` правь пресеты по одному, в порядке их текстов, по разделу «Правка».
   Текст из чата верни исправленным, под ним дай список правок с номерами правил.
