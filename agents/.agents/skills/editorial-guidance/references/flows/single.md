# single

Всю проверку ведёт один агент, без сабагентов. Дальше он называется основным.
Правила, тексты пресетов и результаты механических проверок выведены ниже.

1. Проверь текст по выбранным правилам в порядке их вывода: сначала отдельные
   правила, потом группы пресетов. Результаты механических проверок разбери по
   правилам, названным у каждой проверки. Если проверяется выделение в файле, из
   результатов бери только строки выделения.
2. Без `--fix` ничего не правь и верни отчёт по шаблону.
3. С `--fix` правь пресеты по одному, в порядке их текстов, по разделу «Правка».
   Текст из чата верни исправленным, под ним дай список правок с номерами правил.
