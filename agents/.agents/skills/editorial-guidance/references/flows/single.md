# single

Всю проверку ведёт один агент, без сабагентов. Дальше он называется основным.
Правила и тексты пресетов уже выведены `rules.sh <ru|en> <селекторы>`.

1. Вызови `scripts/rules.sh <ru|en> --checks <селекторы>`. Каждая строка вывода
   называет проверку `scripts/checks.sh` и её правила. Запусти каждую из этих
   проверок. Они читают прозу без frontmatter и блоков кода и выдают номера строк,
   пустой вывод значит, что нарушений нет. Текст из чата сначала сохрани во временный файл (`mktemp`)
   и проверяй его без `file-lines` и `links`. Если проверяется выделение в файле,
   из вывода бери только строки выделения.
2. Проверь текст по выбранным правилам в порядке их вывода: сначала отдельные
   правила, потом группы пресетов.
3. Без `--fix` ничего не правь и верни отчёт по шаблону.
4. С `--fix` правь пресеты по одному, в порядке их текстов, по разделу «Правка».
   Текст из чата верни исправленным, под ним дай список правок с номерами правил.
