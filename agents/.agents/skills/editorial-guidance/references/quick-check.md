# Лёгкая проверка

Режим для фрагмента до пяти предложений из выделения в редакторе или из чата.
Здесь только ссылки на правила. Всё делает один агент, без
сабагентов и без скрипта. Разделы [«Что вычитывать»](../SKILL.md#что-вычитывать) и
[«Где правила пересекаются»](../SKILL.md#где-правила-пересекаются) из SKILL.md
действуют и здесь.

## Порядок

1. Прочитай файлы правил из таблицы [«Применяются»](#применяются) (`rules/<номер>.md`),
   [общего глоссария](glossary/) и проектного глоссария, если проект его подключил
   (см. [SKILL.md](../SKILL.md)).
2. Проверь фрагмент по ним в порядке проходов. Сначала слоп, потом слова,
   грамматика и читаемость.
3. Если фрагмент взят из файла, правь его на месте через Edit. Если он прислан
   в чате, верни исправленный текст.
4. Под текстом дай список правок с номерами правил. Оценки слопа нет.

## Применяются

| Правило | Что проверяется во фрагменте |
|---|---|
| A1 | маркер виден в одной фразе |
| A2 | только если во фрагменте есть вывод или «зачем/почему» |
| B1 | каждое вхождение, без подсчёта плотности |
| B4 | калька видна в одной фразе |
| P1–P3 и [глоссарий](glossary/) | термины и гибриды |
| P4 | пунктуация и согласование |
| P5 | строение предложения |
| P6 | вода внутри фрагмента |
| P8 | полупереводы |
| P12 | соединители |
| P13 | глагол вместо абстракции |
| P14 | метафоры |
| P10, P15 | только для ячейки таблицы или пункта списка |

## Не применяются

| Правило | Почему не подходит фрагменту |
|---|---|
| A3, A4, P7 | нужны соседние разделы или весь список |
| A5 | нужен весь документ, чтобы понять, откуда деталь |
| B2, B3, B5, B6 | считаются по плотности или по всему документу |
| P9 | единообразие проверяется по всему документу |
| P11 | ссылки и навигация проверяются по всему документу |
