# Лёгкая проверка

Режим для фрагмента до пяти предложений из выделения в редакторе или из чата.
Здесь только ссылки на правила. Всё делает один агент, без
сабагентов и без скрипта. Разделы [«Что вычитывать»](../SKILL.md#что-вычитывать) и
[«Где правила пересекаются»](../SKILL.md#где-правила-пересекаются) из SKILL.md
действуют и здесь.

## Порядок

1. Прочитай правила из таблицы [«Применяются»](#применяются) и все файлы
   [глоссария](glossary/), которые подходят к фрагменту по шапке.
2. Проверь фрагмент по ним в порядке проходов. Сначала слоп, потом слова,
   грамматика и читаемость.
3. Если фрагмент взят из файла, правь его на месте через Edit. Если он прислан
   в чате, верни исправленный текст.
4. Под текстом дай список правок с номерами правил. Оценки слопа нет.

## Применяются

| Правило | Что проверяется во фрагменте |
|---|---|
| §А1 | маркер виден в одной фразе |
| §А2 | только если во фрагменте есть вывод или «зачем/почему» |
| §Б1 | каждое вхождение, без подсчёта плотности |
| §Б4 | калька видна в одной фразе |
| §С1–§С3 и [глоссарий](glossary/) | термины и гибриды |
| §С4 | пунктуация и согласование |
| §С5 | строение предложения |
| §С6 | вода внутри фрагмента |
| §С8 | полупереводы |
| §С12 | соединители |
| §С13 | глагол вместо абстракции |
| §С14 | метафоры |
| §С10, §С15 | только для ячейки таблицы или пункта списка |

## Не применяются

| Правило | Почему не подходит фрагменту |
|---|---|
| §А3, §А4, §С7 | нужны соседние разделы или весь список |
| §А5 | нужен весь документ, чтобы понять, откуда деталь |
| §Б2, §Б3, §Б5, §Б6 | считаются по плотности или по всему документу |
| §С9 | единообразие проверяется по всему документу |
| §С11 | ссылки и навигация проверяются по всему документу |
