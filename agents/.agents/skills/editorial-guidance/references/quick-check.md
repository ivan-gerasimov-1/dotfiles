# Проверка фрагмента

Проверка фрагмента до десяти предложений из выделения в редакторе или из чата.
Здесь только ссылки на правила. Всё делает один агент, без
сабагентов и без проверок `checks.sh`. Разделы [«Вызов»](../SKILL.md#вызов),
[«Что вычитывать»](../SKILL.md#что-вычитывать) и
[«Где правила пересекаются»](../SKILL.md#где-правила-пересекаются) из SKILL.md
действуют и здесь.

Список `rules` во frontmatter повторяет номера из таблицы [«Применяются»](#применяются).
По нему `scripts/rules.sh <ru|en> --fragment` отбирает правила для фрагмента на обоих
языках, а поле `languages` в файле правила отсекает правила другого языка. Меняя
таблицу, меняй и список.

## Порядок

1. Правила для проверки выводит `scripts/rules.sh ru --fragment <селекторы>`.
   Это выбранные правила из таблицы [«Применяются»](#применяются). Если скрипт
   назвал правила, которые на фрагменте не проверяются, скажи об этом.
2. Общий глоссарий и [шаблон отчёта](report.md) уже выведены
   `scripts/context.sh ru`. Проектный глоссарий прочитай, если проект его
   подключил (см. [SKILL.md](../SKILL.md)).
3. Проверь фрагмент по правилам в порядке проходов. Сначала слоп, потом слова,
   грамматика и читаемость.
4. Без `--fix` ничего не правь. Верни находки в формате
   [отчёта](report.md). Оценки слопа нет.
5. С `--fix` правь фрагмент из файла на месте через Edit, а фрагмент из чата
   верни исправленным. Под текстом дай список правок с номерами правил.

## Применяются

| Правило | Что проверяется во фрагменте |
|---|---|
| A001 | маркер виден в одной фразе |
| A002 | только если во фрагменте есть вывод или «зачем/почему» |
| B001 | каждое вхождение, без подсчёта плотности |
| B004 | калька видна в одной фразе |
| P001–P003 и [глоссарий](glossary/) | термины и гибриды |
| P004 | пунктуация и согласование |
| P005 | строение предложения |
| P006 | вода внутри фрагмента |
| P008 | полупереводы |
| P012 | соединители |
| P013 | глагол вместо абстракции |
| P014 | метафоры |
| P010, P015 | только для ячейки таблицы или пункта списка |

## Не применяются

| Правило | Почему не подходит фрагменту |
|---|---|
| A003, A004, P007 | нужны соседние разделы или весь список |
| A005 | нужен весь документ, чтобы понять, откуда деталь |
| B002, B003, B005, B006 | считаются по плотности или по всему документу |
| P009 | единообразие проверяется по всему документу |
| P011 | ссылки и навигация проверяются по всему документу |
