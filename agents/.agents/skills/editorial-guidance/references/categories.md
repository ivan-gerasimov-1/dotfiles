# Категории правил

Категория называет вид дефекта, который ловит правило. Её задаёт поле `category`
во frontmatter правила. Одна категория может собирать правила из разных пресетов.

Номер правила начинается с первых двух букв категории в верхнем регистре, за ними
идут три цифры. Правила категории `grammar` получают номера GR001, GR002 и так далее.

| Категория | Дефект |
|---|---|
| `substance` | содержания нет или оно выдумано |
| `padding` | вода и повторы |
| `cadence` | машинный ритм |
| `wording` | неудачный оборот |
| `terms` | термины и англицизмы |
| `grammar` | грамматика, пунктуация и опечатки |
| `structure` | устройство предложений, списков, таблиц и ссылок |
