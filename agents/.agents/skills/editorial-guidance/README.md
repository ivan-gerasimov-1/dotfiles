# editorial-guidance

Устройство скилла для тех, кто его правит. Модель этот файл не читает, всё нужное
для проверки ей выводят скрипты.

## Файлы

Правила и всё для проверки лежат в каталоге [references/](references/):

- [rules/](references/rules/) содержит по файлу на правило, имя файла совпадает
  с номером правила (`rules/P012.md`). Frontmatter файла задаёт `id`, `title`,
  базовый пресет (`set`) и языки, для текста на которых у правила есть прочтение
  (`languages`, например `[ru, en]`). Язык указывается без региона, поэтому `en`
  покрывает и en-US, и en-GB. Примеры в файле правила даны для русского,
  английское прочтение лежит в [english.md](references/english.md).
- [presets/](references/presets/) отвечает на вопрос «что проверять», по файлу
  на пресет. Frontmatter задаёт `id`, `title` и правила. Базовый пресет делит свои
  правила на проходы (`passes`) и в тексте описывает их, чек-листы, оценку и свои
  разделы отчёта. Составной пресет собирается из других (`extends`) или
  перечисляет правила (`rules`).
- [flows/](references/flows/) отвечает на вопрос «как проверять», по файлу на флоу.
- [checking.md](references/checking.md) задаёт, что не проверяется и где правила
  пересекаются.
- [fix.md](references/fix.md) задаёт, как править с `--fix`.
- [report.md](references/report.md) содержит общий шаблон отчёта.
- [subagent-prompt.md](references/subagent-prompt.md) содержит задание сабагенту
  прохода во флоу parallel.
- [glossary/](references/glossary/) содержит общий глоссарий: что не переводить, чем
  заменять и какие кальки допустимы.
- [english.md](references/english.md) даёт английское прочтение правил и английские
  списки маркеров.

## Скрипты

- [scripts/rules.sh](scripts/rules.sh) выводит тексты выбранных пресетов, потом
  правила на языке текста. Про правило, названное по номеру, но не написанное для
  этого языка, он пишет отдельной строкой. `--notes` выводит только тексты
  пресетов, `--passes` выводит проходы, `--ids` выводит номера правил.
- [scripts/context.sh](scripts/context.sh) выводит всё остальное для проверки:
  флоу, [checking.md](references/checking.md), шаблон отчёта, с `--fix` ещё
  [fix.md](references/fix.md). Для single он добавляет глоссарий или английское
  прочтение правил, для parallel задание сабагенту.
- [scripts/checks.sh](scripts/checks.sh) запускает механические проверки
  из чек-листов пресетов.

`rules.sh --check` проверяет, что пресеты и правила сходятся. Запускай его после
правок в пресетах и во frontmatter правил.

## Примеры вызова

| Вызов | Что происходит |
|---|---|
| `/editorial-guidance` | отчёт по `recommended` одним агентом |
| `/editorial-guidance --fix` | правка по `recommended` |
| `/editorial-guidance slop` | отчёт по слопу с оценкой от 1 до 5 |
| `/editorial-guidance full --flow parallel --fix` | правка по всем правилам, сабагенты по проходам |
| `/editorial-guidance P012 B001` | отчёт только по двум правилам |
| `/editorial-guidance fragment <текст>` | отчёт по правилам для короткого текста |
