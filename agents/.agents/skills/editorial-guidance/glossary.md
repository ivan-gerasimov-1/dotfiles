# Глоссарий

Термины продукта и команды для правил §С1–§С3 и §С9 из [prose-rules.md](prose-rules.md)
и допустимые кальки для §Б4 из [slop-rules.md](slop-rules.md).
Правила описывают принцип, здесь лежат конкретные списки. Новый устоявшийся термин
добавляет сюда автор, когда принимает кандидата из отчёта вычитки (§С1). Во время
вычитки глоссарий не правится.

## Содержание

- Не переводить
- Заменять
- Допустимые кальки

## Не переводить

### Термины команды

Не переводятся по §С1.

- задеплоен / задеплоить / деплой — устоявшийся технический термин разработки.
- Lazy-чанки / lazy-чанк — устоявшийся термин сборки (разделение кода в rsbuild / webpack).
- пайплайн — допустимый технический термин.
- маппинг / маппит / маппится — устоявшийся термин для преобразования полей между схемами (MongoDB → ClickHouse, DTO → ответ API).
- flow / флоу — устоявшийся термин для пользовательского сценария или потока экранов (pledge flow, checkout flow). Не переводить как «поток». В формате кода и в составе имени фичи (pledge flow) оставлять английским. В прозе допустимо «флоу».
- downstream / upstream — устоявшиеся термины для положения в потоке данных или зависимостей. Не переводить как «вниз/вверх по потоку» и не разворачивать в «зависимые модули». Оставлять английскими (downstream-модули, upstream-сервис).
- аудит-лог — устоявшийся термин для журнала действий и изменений (модуль `auditLog`). В прозе пишется кириллицей через дефис (аудит-лог, в аудит-логе). Не переводить как «журнал аудита» и не разворачивать. Продуктовый модуль называется Audit Log (см. названия модулей ниже).
- эндпоинт в прозе пишется кириллицей (эндпоинт, эндпоинта). Не заменять на «endpoint» и не переводить как «точка входа/доступа». В формате кода остаётся путь или имя маршрута.
- feature-флаг — устоявшийся термин для флага включения фичи. Не разворачивать в «флаг включения для организации».
- e2e-тесты — тесты сценария целиком (end-to-end). Не переводить как «сквозные тесты».
- билд-агент — машина, на которой Jenkins запускает пайплайны. Не переводить как «агент сборки».
- Jenkins-файл — файл с описанием пайплайна в Jenkins (`Jenkinsfile`). В прозе пишется «Jenkins-файл».
- namespace — пространство имён в Kubernetes. Пишется латиницей и не транслитерируется («неймспейс»).
- stacked PR — цепочка PR, где каждый следующий строится на предыдущем.
- скилл — пакет инструкций для агента (каталог с `SKILL.md`). Не переводить как «навык».
- сабагент — агент, которого другой агент запускает для части работы. Не переводить как «подагент».
- промпт — текст задания для модели. Не переводить как «запрос» или «подсказка».
- слоп — текст со следами машинной генерации. Производные тоже не переводятся (слоп-маркер, слоп-отчёт, антислоп-сигнал).
- заголовок в подбор — короткий заголовок, набранный жирным в одну строку с текстом пункта списка или абзаца. Типографский термин, его не заменяют описанием.
- чек-лист — список проверок, которые проходят по порядку.

### Имена сущностей кода

В формате кода, регистр как в коде.

- Агрегаты и модели: `Subscription`, `Widget`, `Charge`, `Customer`, `PaymentIntent`.
- Классы и сервисы: `CreateEntitiesFactory`, `JobProcessor`, `WidgetSession`.
- Поля: `checkoutTypes.pledge`, `isPledge`.
- Перечисления: `ECheckoutType`, `ECheckoutType.Pledge`, `IWidgetCheckoutTypes`.
- Типы TypeScript: `Record<ECheckoutType, X>`.
- Методы и декораторы: `Subscription.create`, `@IsEnum`.
- Очереди и каналы: `payment finish`, `post-donation`.

### Названия

- **Модули продукта:** Campaign Pages, Campaign Page, Checkout Modal, Dashboard, Donor Portal, Integrations, Insights, Virtual Terminal, Elements, Gift Catalog, P2P, Audit Log, Ticketing.
- **Внутренние инструменты:** FruAI.
- **Фичи (имена собственные):** Pledges, Faith-Based, Pledge.
- **Технологии:** MongoDB, ClickHouse, Kafka, AJV, Redis, S3, NestJS, Koa, Mongoose, Sentry, TypeScript.
- **Архитектурные стандарты:** ADR-NN, NeverError.

### Термины

- **Аббревиатуры разработки:** DTO, REST, API, UI, enum, MVP, PII, CRM, ML, SDK, CDN, PR, TD, PoC, CI, LLM, RFC.
- **Роли:** SDET.
- **Предметная область:** recurring, pledge, installment, upsell, donation, donor, fundraiser, supporter, tribute, designation, recurring plan (в коде это `Subscription`, для пользователя Recurring Plan).
- **Общетехнические (устоявшиеся):** snapshot, interceptor, frontmatter. Не переводятся. «Слепок» допустим только как пояснение к snapshot в определении (не «снимок»).

## Заменять

| Термин | Замена |
|---|---|
| owner | «владелец» |
| донация | «донат» |
| feature-gate, per-company flag | «feature-флаг». Если важен уровень, «feature-флаг на уровне организации» |
| session-events | «события сессии» |
| пречеки (этапы пайплайна) | «предварительные проверки» |
| жирный лид, lead-in | «заголовок в подбор» |
| bucket, бакет (в трекинге) | «источник» (например, «бакет CAMPAIGN_PAGE» → «источник CAMPAIGN_PAGE») |

## Допустимые кальки

Устоявшиеся кальки, которые §Б4 не помечает.

- «источник истины» (source of truth).
- «исчерпывающий switch» (exhaustive switch).
