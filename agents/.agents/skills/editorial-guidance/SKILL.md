# Editorial Guidance

Ты редактор технического текста. Проверяешь готовый текст по выбранным правилам
и выдаёшь отчёт с находками, с `--fix` правишь их.

## Что проверять

Текст или документ, над которым мы сейчас работаем. Определи его так:

1. Если текст передан в вызове или выделен в редакторе, берёшь его.
2. Если пользователь явно указал файл, берёшь его.
3. Иначе смотришь на открытый или обсуждаемый в текущей сессии документ.
4. Если непонятно, спроси, какой файл проверять. Не угадывай молча.

## Вызов

`/editorial-guidance [селекторы] [--flow single|parallel] [--fix] [файл или текст]`.
Другие скиллы пишут вызов так же, например «`editorial-guidance prose --fix`».

**Селекторы** выбирают правила: имя пресета или номер правила, например `GR003`.
Правила нескольких селекторов объединяются. Без селекторов действует `recommended`.

| Пресет | Назначение |
|---|---|
| [`recommended`](references/presets/recommended.md) | набор по умолчанию, для фрагмента и для большого текста |
| [`light`](references/presets/light.md) | быстрая проверка по скриптам и узнаваемым оборотам |
| [`prose`](references/presets/prose.md) | правила языка |
| [`slop`](references/presets/slop.md) | правила слопа с оценкой от 1 до 5 |
| [`full`](references/presets/full.md) | все правила |

**`--flow`** решает, как идёт проверка. По умолчанию действует `single`.

| Флоу | Как идёт проверка |
|---|---|
| [`single`](references/flows/single.md) | всю проверку ведёт один агент |
| [`parallel`](references/flows/parallel.md) | каждую группу проверяет свой сабагент: дороже, но длинный документ проверяется тщательнее |

**`--fix`** решает, править ли текст. Без него скилл выдаёт отчёт с находками
и заменами, текст не меняется. С ним скилл правит файл на месте, а текст из чата
возвращает исправленным. Если после отчёта просят поправить, запусти те же
селекторы с `--fix` и начни с находок отчёта.

## Как выполнять

1. Определи текст по разделу [«Что проверять»](#что-проверять).
2. Вызови `<каталог скилла>/scripts/prompt.ts <селекторы> [--flow parallel] [--fix] <файл>`
   по полному пути. Текст из чата передай вместо файла через stdin:

   ```bash
   <каталог скилла>/scripts/prompt.ts <селекторы> - <<'EOF'
   <текст>
   EOF
   ```

   Скрипт печатает флоу, шаблон отчёта, правила и результаты механических
   проверок. Файлы скилла отдельно не открывай. Язык текста скрипт определяет сам
   и называет в первой строке. Если он ошибся, повтори вызов с `--lang ru` или
   `--lang en`. Если вывод сохранён в файл, прочитай этот файл целиком.
3. Действуй по выведенному флоу.
