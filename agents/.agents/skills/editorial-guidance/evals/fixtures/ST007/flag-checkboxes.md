### Контекст и цель

Чтобы исключить аккаунт из экспериментов, поддержка просит разработчиков поправить список исключений вручную. Цель: поддержка делает это сама из админки.

### Что делаем

На странице аккаунта в админке появляется переключатель «Исключить из экспериментов». Изменение сразу попадает в список исключений.

### Критерии завершённости

- [ ] На странице аккаунта в админке есть переключатель «Исключить из экспериментов».
- [ ] `ExclusionList.add` вызывается при включении переключателя.
