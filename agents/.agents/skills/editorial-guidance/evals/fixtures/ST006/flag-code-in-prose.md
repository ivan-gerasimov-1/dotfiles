### Контекст и цель

Сейчас `WidgetSessionService` пишет `null` в `amountHint`, поэтому виджет не показывает размер одного платежа. Цель: виджет показывает размер одного платежа.

### Что делаем

`WidgetSessionService` заполняет `amountHint` из условий рассрочки.

### Критерии завершённости

- Виджет рассрочки показывает размер одного платежа.
