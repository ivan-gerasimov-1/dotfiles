### Контекст и цель

Сейчас сервис сборки сессии оплаты не заполняет размер одного платежа, поэтому виджет его не показывает. Цель: виджет показывает размер одного платежа.

### Что делаем

Сервис сборки сессии оплаты заполняет размер одного платежа из условий рассрочки.

### Критерии завершённости

- Виджет рассрочки показывает размер одного платежа.

### Где смотреть (ориентиры)

```
// отправные точки, реализация может отличаться
WidgetSessionService — сборка сессии оплаты (сейчас пишет null)
amountHint           — размер одного платежа
```
