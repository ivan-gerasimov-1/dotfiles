### Админка

**Раздел FAQ** появляется в настройках каталога после раздела «Категории». Вопросы сохраняются из модалки сразу, без общей кнопки сохранения.

Заголовок блока и флаг включения сохраняются вместе с остальными настройками.

### Синхронизация с S3

**Конфиг каталога** получает флаг блока и список вопросов. Вопросы попадают в конфиг, только когда блок включён.

Тексты вопросов собираются по языкам при каждой сборке конфига.
