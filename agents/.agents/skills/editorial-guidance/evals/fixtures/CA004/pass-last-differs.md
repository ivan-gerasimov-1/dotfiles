### Админка

**Раздел FAQ** появляется в настройках каталога после раздела «Категории». Вопросы сохраняются из модалки сразу, без общей кнопки сохранения.

Заголовок блока и флаг включения сохраняются вместе с остальными настройками.

### Синхронизация с S3

**Конфиг каталога** получает флаг блока и список вопросов. Вопросы попадают в конфиг, только когда блок включён.

Тексты вопросов собираются по языкам при каждой сборке конфига.

### Листинг каталога

Блок выводится под товарами и пагинацией на каждой странице листинга, даже когда поиск ничего не нашёл. В каталоге без товаров блока нет.

Язык вопроса листинг выбирает для пары из вопроса и ответа. Если на языке каталога переведены оба, показывается перевод, а если хотя бы одного перевода нет, вся пара берётся с основного языка каталога, чтобы вопрос и ответ не оказались на разных языках.
