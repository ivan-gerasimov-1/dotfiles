### Контекст и цель

Поле даты окончания обязательства переезжает в новую коллекцию. Старая версия сервиса читает поле из старой коллекции, поэтому порядок выкатки важен.

### Что делаем

1. Миграция копирует дату окончания в новую коллекцию.
2. Выкатывается версия сервиса, которая читает обе коллекции.
3. Через неделю без ошибок поле удаляется из старой коллекции.

### Критерии завершённости

- После шага 2 экран подтверждения показывает дату окончания для старых и новых обязательств.
- После шага 3 в старой коллекции поля нет.
