## AS IS

Флаг `experimentsDisabled` — единственный механизм, который глобально выключает эксперименты для аккаунта. Его выставляют вручную, синхронизации с внешними источниками нет.

## TO BE

В сущность `Account` добавляется поле `experimentStatus`. Значения для него раз в сутки приходят из CRM, и контроллеры экспериментов на бэкенде и фронтенде начинают их учитывать. Решение очевидное.

## Синхронизация

Задача синхронизации пишет значения в MongoDB через `$set` по ключу аккаунта. Повторный запуск даёт тот же результат. Без сюрпризов.

## Мониторинг

Новых метрик и алертов не нужно. Падения задачи попадают в Sentry через общую обработку фоновых задач.
